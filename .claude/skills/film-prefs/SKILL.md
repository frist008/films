# Предпочтения

| Что сказал владелец | Куда записать |
|---|---|
| важные люди | `config/people.toml`: `name` (как в TMDB), `imdb_id`, **`tmdb_id`** (взять из таблицы `people` — у людей из TMDB нет IMDb id, имена бывают не латиницей: Миядзаки = «宮崎駿»), `weight`; проверить, что `films rank` показывает совпадения (`people_hits`) |
| важный человек — создатель / шоураннер / продюсер (не актёр и не режиссёр) | в `config/people.toml` у него `crew = true` → `python -X utf8 -m films crew` (роли Creator / Executive Producer / Producer / Showrunner / Story / Writer / Director из кэша TMDB + один `combined_credits` на человека → таблица `person_crew`; сезоны — через сериал), затем проверить `people_hits` в `films rank` (R75) |
| «для сериала X озвучка Y — приоритет» (напр. «Для Рика и Морти озвучка Кубик в Кубе или Сыендук приоритет», 2026-10-25) | `config/settings.toml [voice_preference] series`: `{tmdb = <id сериала>, name, studios = [названия студии и их варианты в раздачах: «Сыендук», «sndk», …]}` — раздачи с этими студиями становятся лучшими для всех сезонов (`rank.preferred_studios`), затем обычный порядок «дубляж > многоголоска > …»; проверить лучшую раздачу сезона в `films rank` |
| «следить за франшизой X», «X — следить за всем» | `config/franchises.toml`: `[[franchise]]` key, name, `scope = "all"` (все годы и будущее) / `from_year = 2024` («с 2024 и дальше») / `scope = "none"`, `tmdb_collections`, `note` с датой и словами владельца; аниме — `anime = true` (R44). Франшиза = вся вселенная (фильмы, сериалы, мультфильмы, спин-оффы) — состав собирает `films.franchise resolve` (`docs/franchises.md`) |
| «я видел X» | не здесь — скил `mark-watched` (только по его словам) |
| тайтлы Димы (2024/2025) | `config/dima.toml` + `responsibility (source='manual')`; снять `auto_suggested`, которых нет в списке — спросить |
| список желаемого | `store_status (store='google_play', in_wishlist=1)` |
| «озвучка не нужна» | `titles.no_dub_needed = 1` |
| хочу / глянуть / нейтрально / заказ (+ кто) | `user_marks` |
| «не интересен», «не буду смотреть» | `user_marks.mark = 'not_interested'` — тайтл скрывается, из БД не удаляется |
| порядок сортировки, пороги | `config/settings.toml` |

Каждое название сопоставить с тайтлом в БД (по всем названиям + год). Неоднозначно — спросить.
Не найдено в БД — сказать владельцу и предложить добавить. После изменений — `rebuild-sheet`
(и `responsible-playlist`, если менялся список Димы). Ответ: что записано, что не сопоставилось.
Новые правила (не просто данные) — также записать в CLAUDE.md, раздел «Решения».
