# Отметить просмотренным

**Только по словам владельца** («я видел X», «видел всё», его постоянное поручение переносить Jellyfin → Plex).
Купил, скачал, было в старой таблице, догадка — не повод отмечать. Сомнение, что именно он видел (вселенная из
фильмов, сериалов, аниме), — спросить чекбоксами (скил `owner-survey`), потом отмечать.

1. **Найти тайтл**: `python -X utf8 -m films watched find <название или IMDb id>` (ищет по RU/UK/оригинальному/
   латинскому названию). Несколько кандидатов → спросить владельца (название, год, сезон, режиссёр).
   Сериал: «видел 2 сезон X» → строка нужного сезона (каждый сезон — отдельный тайтл).
   Нет в БД (старый фильм) → создать тайтл из TMDB: `films.link.ensure_movie(conn, imdb_id, "manual")`, потом отметить.
2. **Отметить**: `python -X utf8 -m films watched mark <title_id>` — делает всё через API Plex:
   - есть в библиотеке сервера → `/:/scrobble` (у владельца на сервере);
   - всегда также Plex Discover (`PUT discover.provider.plex.tv/actions/scrobble`) — чтобы просмотр был в аккаунте
     plex.tv, даже если файла нет; для сезона — id сезона;
   - читает состояние обратно и пишет `confirmed`; в БД `watched` (`manual`, и `plex` при подтверждении);
   - записывает `sync_state('plex_mark')`.
   - **и в Jellyfin** (владелец, 2026-10-25: «Да, и в Jellyfin»): `films/sources/jellyfin_guard.py` — фильм и каждая серия,
     если они есть в Jellyfin; уже просмотренное не трогает, снимать отметки нельзя (хук `jellyfin-guard.sh`). Ключа API
     нет (владелец, 2026-10-26: «Никакого ключа у тебя есть доступ в хром чтобы всё делать и там скрипты гонять если
     надо») → в ответе `jellyfin: no API key` — тогда через вкладку Jellyfin в Chrome (`http://localhost:8096`, вход
     есть): `python -X utf8 -m films.sources.jellyfin_chrome code --title <id>` (серия — `--episode <imdb> <сезон>
     <серия>`; несколько фильмов — `--titles <id>,<id>,…`, сезон целиком — `--season <imdb> <сезон>`: всё одним вызовом,
     одно подтверждение, R274) → этот текст целиком одним `javascript_tool` во вкладке Jellyfin → в ответе по каждому id `already` /
     `played: true` / `error`; ошибку — владельцу. Другой JS с отметками хук `jellyfin-chrome-guard.sh` не пропустит.
   `--dry-run` — только проверить, что Plex находит тайтл. Если `confirmed: false` — сказать владельцу, не скрывать.
   Для сезона `confirmed` по Discover может не прийти (сезон не отдаёт viewState) — проверить серии поштучно
   (`plex.discover_children` — Discover отдаёт детей страницами по 20, хелпер листает по 200).
   «Видел только серии N…M» — не отмечать сезон целиком: `films.watched.mark_episode(conn, series_imdb, season, ep)`.
   Тайтла нет в БД: фильм — `films.link.ensure_movie(conn, imdb_id, "manual")`, сезон — `ensure_season(conn, tmdb_tv_id, n)`.
   Перенос просмотров Jellyfin → Plex — `films watched from-jellyfin` (поручение владельца, R43).
3. **Магазины**: если тайтла нет в желаемом и он продаётся — поставить в очередь `store-sync` (добавление в желаемое).
4. Пересобрать таблицу (скил `rebuild-sheet`): тайтл уходит со всех листов, кроме «Просмотренные».
5. Ответить коротко: что отмечено, где (сервер / аккаунт), подтвердил ли Plex.

Несколько тайтлов в одном сообщении — обработать все, ни одного не пропустить.

## Сериал целиком или по сезоны (2026-10-23)

«Видел сериал X» / «до N сезона» → `films.watched.mark_series(conn, tmdb_tv_id, seasons=None|[1..N])`: каждая сезон-строка и **каждая серия** (Plex Discover хранит состояние по сериям; отметка сезона целиком там не видна). Тайтл искать по TMDB (`/search/tv`), не по русскому названию в базе. «Серии, что лежат в папке Plex, — не видел» (Миротворец, Агенты Щ.И.Т.): отметить серии до первой лежащей в папке. Ошибочную отметку снять `watched.unmark`.

## Никогда не отмечать повторно (владелец, 2026-10-23)

Каждая отметка в Plex добавляет запись в историю с текущей датой и сдвигает «последний просмотр» — повторная отметка уже просмотренного **ломает хронологию владельца**. Перед любой отметкой проверить viewCount/viewState (библиотека и Discover) и пропустить просмотренное (`watched.mark` / `mark_episode` так и делают). Сезон целиком не отмечать — только непросмотренные серии. Ничего не снимать (`unmark*`) с того, что владелец мог смотреть сам. Удалять записи из истории (`removeActivity`) — только с явного «да» владельца на конкретный список.

## Аниме «видел всё до серии N, по канону» (R89, 2026-10-24, Ван-Пис)
- Филлеры — animefillerlist.com (`/shows/<slug>`, обычный HTTP; таблица серий: `<tr class="manga_canon|mixed_canon/filler|filler|anime_canon">`, `<td class="Number">`, `<td class="Date">`). Mixed и anime canon = канон. Нет списка — ничего не отмечать.
- Сопоставление абсолютного номера с сезоном: блоки сезонов TMDB подряд (`tmdb.season_raw`); у длинных аниме (Ван-Пис) TMDB и Plex Discover хранят **абсолютный** номер серии внутри сезона-арки — проверить `discover_children` сезона до отметки; даты TMDB сверить с датами animefillerlist.
- Отметка — только `watched.mark_episode` по каждой серии; строка `watched`: сезон без филлеров → `manual`, с пропущенными филлерами → `manual_partial`, сезон целиком из филлеров — без строки.
- «Фильмы до даты последней просмотренной серии» — члены франшизы (`franchise_members`, movie) с `release_date_primary` раньше даты выхода этой серии, кроме лежащих на диске (`disk_files.present = 1` — скачано = не видел); `link.ensure_movie` → `watched.mark`.
- Фильмы в папке серий бывают названы номером серии (`[1030]…2.mkv` = Film Red): проверять ffprobe (тег title, длительность, субтитры, кадр `ffmpeg -ss … -frames:v 1`), привязку — в `data/disk_map.json` (`match` по имени файла).
- Перед отметкой проверить `plex_items` сезона: одно Plex-имя шоу может покрывать два сериала (аниме и Netflix «One Piece») — иначе `mark_episode` отметит чужие файлы.
