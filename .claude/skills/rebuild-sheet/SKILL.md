Обратное чтение сравнивает таблицу **со снимком записанного в прошлый раз** (`data/cache/sheet_written.json`), а не с
текущим расчётом: иначе устаревшая таблица откатит изменения, сделанные с тех пор (ошибка 2026-10-23). Нет снимка —
ответственных из таблицы не читать. После пересборки проверить счётчики read_back: большое число «изменений» без
правок владельца = ошибка, остановиться и разобраться.

# Пересборка таблицы

Доступ: таблица на <google.main>, OAuth-клиент — проект GCP `films-db` на <google.cloud>. Нет `secrets/google_oauth_client.json`
или `.env` — взять из заметки Google Keep «films — секреты» (<google.cloud>). См. `docs/google-setup.md`.

1. **Считать пометки** из текущей таблицы (колонки «Метка», «Заказчик», «Заметка», «Ответственный»)
   в `user_marks` / `responsibility`. Строки сопоставлять по скрытой колонке `title_id`, не по названию.
   Если таблица недоступна — **не пересоздавать** (иначе пометки потеряются), сообщить владельцу.
2. Посчитать фильтры и сортировку по правилам CLAUDE.md и `config/settings.toml`.
3. Пересоздать листы:
   - **Главная / Сериалы / Мультфильмы / Мультсериалы / Аниме** (R77, `sheet._tab`: аниме — категория трекера, затем мульт/обычное × фильм/сезон) — отфильтрованное и отсортированное, метки владельца считываются со всех этих листов; 🟢 апгрейды наверху с колонками «У меня» / «Доступно»;
     колонки (`sheet.MAIN_COLUMNS`) по опросу метаданных (владелец, 2026-10-25): люди — русским написанием, иначе оригинал
     (`people.name_ru`, `films.title_meta people`); «Оператор» (до 2), «Продюсеры» (до 3; у фильмов — Producer, у сезонов —
     Executive Producer) рядом с «Режиссёр» / «Сценарист»; «Дистрибьютор» (IMDb: украинский → единственный мировой → США,
     страна в скобках) и «Ключевые слова» (первые 6 из TMDB, по-английски — переводов у TMDB нет) после «Студия»;
     в ячейке «Ссылки» — Трейлер · IMDb · RT · Картинка · Вики (uk, иначе «Вики (en)») · Сайт (официальный, TMDB);
   - **Просмотренные** — куплено / в желаемом / можно купить (цена, % скидки) / нет в магазине;
   - **Обновить качество** — фильмы `[quality_watch]`: лучшее доступное против копии владельца; колонка «Добавлено в Plex»
     (дата добавления копии, `plex_items.added_at`) — только на этом листе (владелец, 2026-10-25);
   - **Купить**, **Плейлисты** (ссылки и число трейлеров), **Баллы** (разбивка сортировки по признакам);
   - **Нет на трекерах** (R163, владелец 2026-10-25) — члены франшиз без раздач, не просмотренные и не скрытые правилами франшиз; «анонс — ещё не вышел» отдельно (`sheet._not_found_rows`);
   - **Все** — вся БД без фильтров (+ колонка «Почему скрыт»).
4. Выпадающий список «Метка» (🔴 Очень хочу / 🟡 Глянуть / ⚪ Нейтрально / 🟣 Заказ) и условное
   форматирование; приоритет цвета: метка > 🟢 апгрейд > 🔵 Дима.
5. Проверить: число строк на листах совпадает с ожидаемым из БД; пометки владельца на месте.
6. Дать владельцу ссылку и сводку (сколько строк, сколько скрыто и почему).

## Вид таблицы (ревью владельца 2026-10-25 — обязательно)
Никаких колонок и листов, которых владелец не просил; название — слева и закреплено, оригинал — с новой строки, смайлик списка —
в начале названия; лист «Баллы» = константы, колонка «Баллы» в каждом листе = формула; сезоны и франшизы подряд; полный список
правил — CLAUDE.md «Цвета и вид таблицы». Листы переименовывать на месте (`updateSheetProperties`), не пересоздавать.
