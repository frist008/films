# Плейлисты ответственных

Ответственные — `config/settings.toml` `[responsible.<key>]` (имя, правило: жанр / `animation`, годы авто и
предположения, `list` — ручной список владельца `config/<key>.toml`). Плейлист — `[youtube] <key>_playlist_id`.
Сейчас: `dima` (Дима, комедии), `yana` (Яна, мультфильмы). Тем же способом — плейлисты списка владельца
(`films/kostya_list.py`): «Костя Хочет» (❤️), «Вероятно хочу» (💛/🟡), «Возможно» (без смайлика). **Все плейлисты —
доступ по ссылке** (владелец, 2026-10-23). `must_download` в списке (🟢) — тайтл в самый верх таблицы.

1. **Список тайтлов**: сначала применить ручной список — `python -X utf8 -m films.responsible <key>` (каждое
   название → тайтл через TMDB, ответственность `manual`; неоднозначное у мультфильмов решается по признаку
   «анимация», иначе — **спросить владельца**, не угадывать; год в списке снимает неоднозначность).
   Автоправило (`films.rank.apply_responsible`) даёт `auto` / `auto_suggested`; в плейлист — `manual` и `auto`
   (`auto_suggested` — после подтверждения владельцем). Порядок: год ↑, дата выхода ↑, название.
2. **Русский трейлер** у каждого (`titles.trailer_ru_url`). Нет → `python -X utf8 -m films.sources.youtube trailers
   --ids <id,…>`, затем скил `trailer-check` (русская речь должна быть подтверждена). Не нашёлся — в отчёт.
3. **Плейлист**: id пуст → создать в Chrome на канале <youtube.channel> (проверить, что выбран именно этот канал),
   название «Для <Имя>», видимость «Доступ по ссылке», записать id в `[youtube] <key>_playlist_id`.
   Действие от имени владельца — только по его просьбе (CLAUDE.md, правило 5).
4. **Синхронизация**: добавить отсутствующие, убрать тайтлы, которые больше не за этим ответственным, выставить
   порядок по пункту 1, без дублей. В Chrome — пачками, вкладку закрыть.
   После **любого** изменения состава или порядка плейлиста — `python -X utf8 -m films.playlist_notes build`
   (описания должны быть готовы заранее, R68).
5. Сверить итог с ожидаемым списком (количество и порядок), отчитаться: что добавлено / убрано, каких трейлеров
   нет, ссылка на плейлист. Итог — в PLAN.md.

## Как работать с плейлистами в Chrome (проверено 2026-10-24)

Вкладка youtube.com, канал проверить через `youtubei/v1/account/account_menu` (`activeAccountHeaderRenderer.channelHandle` = `<youtube.channel>`, `DELEGATED_SESSION_ID` пуст). Создание сразу с видео и порядком: `youtubei/v1/playlist/create` `{title, privacyStatus: 'UNLISTED', videoIds: [...]}` (SAPISIDHASH, как в docs/stores.md). Проверка — `browse` `VL<id>` с продолжениями (`continuationCommand`, по 100): число, порядок, какие ролики не встали (недоступны в UA / удалены). Существующие плейлисты — `browse FEplaylist_aggregation` (не плодить дубли). id — в `config/private.toml [youtube] playlist_<key>`.
**В плейлист идёт только то, что видно в таблице, в её порядке** (`playlist_notes.visible_order`: просмотренное, IMDb < 5, без озвучки, «не интересен» — нет). **В плейлист не идут** (владелец, 2026-10-24): `[playlists] skip_franchises` (Марио, Крёстный отец — приоритет без трейлера); сериалы (никогда; ответственных за сериалы нет); скачанное (Plex, Jellyfin, диски) и стоящее в очереди qBittorrent (`seen_survey.have`); `[playlists] skip_imdb` («Крёстный отец» — только сортировка); ролики длиннее 5 мин (целые фильмы) и недоступные в UA (YouTube их прячет: «Недоступные видео скрыты» — после правки читать плейлист с `params: 'wgYCCAA%3D'` и удалять то, чего нет в обычном чтении). Трейлер короче 1:30 — тизер, искать длиннее.
**Синхронизация** (ссылка не меняется): нужный порядок роликов — `playlist_notes.members` (уже с заменой продолжения на первый невиденный фильм серии, Дима — только комедии 1-го/2-го жанра, Яна — только мультфильмы, без DC/Marvel) → `youtubei/v1/browse/edit_playlist` `{playlistId, actions}`: `ACTION_REMOVE_VIDEO {setVideoId}`, `ACTION_ADD_VIDEO {addedVideoId}` (пачками по 50), порядок — с конца `ACTION_MOVE_VIDEO_BEFORE {setVideoId, movedSetVideoIdSuccessor}`. Чтение плейлиста сразу после правки отдаёт старое состояние — проверять через несколько секунд. Долгое — запускать промисом в странице (`window.__syncJob`) и опрашивать результат: один вызов javascript_tool живёт 45 с.

**Порядок работы (2026-10-24, после ошибок, найденных владельцем):** (1) `python -X utf8 -m films.playlist_notes desired` —
единственный источник состава; он **падает** при любом нарушении правил ниже; (2) на вкладке youtube.com загрузить код
`films/browser/playlist_sync.js` (не держать код только в странице — перезагрузка вкладки уже оборвала синхронизацию),
затем ровно `data/cache/playlists_desired.js` (хук `playlist-guard.sh`), затем `__plRunAll({key: id, …})` (id из
`config/private.toml`); (3) опрашивать `window.__plRun` (там же `localStorage['plRun']`); у каждого плейлиста в итоге
должно быть `orderOk: true`, `notAdded`, `extra`, `hiddenRemoved` пустые; (4) независимая сверка правил по
`playlists_desired.json` (франшизы Яны, повторы, отслеживаемые франшизы, сериалы, коллекции подряд); (5)
`playlist_notes build`; (6) пункт плана закрыть только после сверки.
**Ещё правила владельца (2026-10-24):**
- **Франшиза — там, где её первый фильм** (владелец, 2026-10-24: «приоритет у первой части, чтобы всё лежало там, где она, и без дубликатов в других»): продолжения переносятся к первой части, даже из «Для Димы» / «Для Яны»; не переносится только то, что ответственному запрещено (исключённые франшизы, короче 60 мин).
- **Один фильм — один плейлист**: Дима / Яна → «Костя Хочет» → «Вероятно хочу» → «Возможно» (`PRECEDENCE`); в Костиных
  плейлистах нет того, что у Димы или Яны; ни фильм, ни ролик не повторяются.
- **Франшиза, за которой владелец следит, — без трейлера** («Хищник — франшиза, которую мы утвердили … что он делает в
  трейлерах?»): фильмы с баллами франшизы в таблице и `[top]` («Хитрый койот», «Дьявол носит Prada 2», «Аббатство
  Даунтон») в плейлисты не идут (`playlist_notes.followed`). Так же — части коллекции TMDB, другая часть которой скачана,
  в очереди или просмотрена («Я иду искать» скачан → трейлер второй части не нужен).
- Яна не любит DC, Marvel, Человека-паука, Марио, «Звёздные войны» (`exclude_franchises`); их мультфильмы — Костины, в
  таблице на «Главной» / «Сериалах» (`owner_cartoons`).
- Тизер (< 1:30) — искать длиннее широко (6 запросов: «трейлер», «русский трейлер», «{год} трейлер на русском», ориг. +
  «дублированный», «HD», «официальный»); каждый найденный проверять глазами (название фильма, не другой фильм с похожим
  именем) — «Супер 8» стоял тизером 1:24, хотя русских трейлеров 2:00+ на YouTube много.

## Части фильма (владелец, 2026-10-23)

Если у тайтла есть части (1, 2, …) — в плейлист кладём **только трейлер первой непросмотренной части**; трейлеры продолжений не добавляем («если песня понравилась, то и вторую будем смотреть»). Касается всех плейлистов: «Костя Хочет», «Вероятно хочу», «Возможно», «Для Димы», «Для Яны».

## Описание фильмов плейлиста (R68, 2026-10-23)

Владелец может в любой момент перед включением плейлиста попросить кратко рассказать, что в нём:
«описание к плейлисту X», «что в плейлисте X», «кратко про фильмы плейлиста», «о чём фильмы в „Для Яны“» и т.п.
Ответ — **сразу**, из заранее готового файла, без поиска и пересказа:

| Плейлист | key | файл |
|---|---|---|
| «Костя Хочет» | `kostya_want` | `data/cache/playlist_notes/kostya_want.md` |
| «Вероятно хочу» | `probably` | `data/cache/playlist_notes/probably.md` |
| «Возможно» | `possible` | `data/cache/playlist_notes/possible.md` |
| «Для Димы» | `dima` | `data/cache/playlist_notes/dima.md` |
| «Для Яны» | `yana` | `data/cache/playlist_notes/yana.md` |

1. Если плейлист менялся после `generated_at` в `data/cache/playlist_notes/index.json` (новые ответы опроса ❤️ в
   `data/cache/kostya_want_answers.json`, правки списков, новые «видел») — сначала
   `python -X utf8 -m films.playlist_notes build` (секунды, БД только на чтение, TMDB из кэша; `--online` — дозапросить
   недостающее в кэше TMDB).
2. Выдать владельцу содержимое файла как есть (`python -X utf8 -m films.playlist_notes show <key>`): номер, русское
   название, год, **оригинальное** русское описание TMDB (ru-RU overview дословно, 1–2 предложения, ≤ 300 знаков).
   Не пересказывать и не сочинять; нет русского описания — «описания нет» + первое предложение описания на языке
   оригинала с пометкой языка («(англ.)»).
3. Состав = тот же, что в плейлисте: без просмотренного (кроме `*_partial`), из частей одной коллекции TMDB / сезонов
   одного сериала — только первая непросмотренная (R66). Строка «⚠ раньше вышла часть …» — у фильма есть более ранняя
   часть, не отмеченная в базе просмотренной и отсутствующая в плейлисте: спросить владельца, видел ли он её
   (если да — скил `mark-watched`), иначе плейлист должен начинаться с неё.

**Правило:** `films.playlist_notes build` перезапускается после **каждого** изменения любого плейлиста (синхронизация
по этому скилу, новые ответы опроса «Костя Хочет», правки `config/dima.toml` / `config/yana.toml`, большого списка,
отметки «видел»), чтобы описания всегда были готовы заранее.

## Названия-«паразиты» (владелец, 2026-10-23)

Если русское название фильма паразитирует на имени франшизы, но к ней не относится («Синистер. Пожиратель душ» ≠ «Синистер»), в описании к трейлеру/плейлисту прямо писать: «к франшизе «…» не относится».
