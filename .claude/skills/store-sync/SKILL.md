# Магазины

Работает через **Chrome** (сессия <google.main>). Если открыт не тот аккаунт — остановиться и сказать владельцу.

Факты о магазинах (`docs/stores.md`): Google Play Фильмы в Украине закрыт (403) — покупки идут через YouTube
(«Фильмы → Покупки»); список желаемого владельца — **список просмотра Google TV**. Данные — таблица `store_items`
(`owned`, `in_wishlist`, `available`, `price`, `discount_pct`, `raw` JSON: `audio_langs`, `duration`, `youtube_library_vid`…).

1. **Купленное**: «Покупки» YouTube и библиотека Google Play / Google TV → `store_items.owned = 1`.
2. **Желаемое**: список желаемого Google Play → `store_items.in_wishlist = 1`; для каждого — цена, валюта, скидка %
   (если есть старая цена), доступность к покупке.
3. **Просмотренные** (`watched`): для каждого найти карточку в магазине (по оригинальному, латинскому,
   RU, UK названию + год). Нет в магазине → `available = 0` (лист «Просмотренные»: «нельзя купить — отсутствует»).
4. **Добавление в желаемое** (= список просмотра Google TV): только `films/browser/gtv_watchlist_guard.js` — загрузить файл как есть во вкладку google.com (`javascript_tool`), затем `await __gtvGuard.add({id, names:[orig, ru, uk], year})` по одному. Кнопка «Хочу посмотреть» в карточке фильма Поиска переключается: на уже добавленном она **удаляет** и сбрасывает дату — предохранитель жмёт только при `aria-pressed=false` и проверяет результат; хук `gtv-guard.sh` блокирует остальное (владелец, 2026-10-24). Что уже в списке — смотреть по кнопке (`__gtvGuard.check`), а не только по `store_items` (там не всё сопоставлено: «Престиж» был в списке, в БД — нет).
   **Блок Google** (429 + `/sorry`, «необычный трафик»; капчу не проходить): первый блок 2026-10-24 — с ~06:33 до ≤ 08:53 (≈ 2 ч 20 мин, конец не замерен точно). Цикл проверяет поиск перед каждым фильмом (`__gProbeBlocked`), при блоке ждёт, перепроверяя раз в 10 мин, и пишет начало/конец в `__gBlocks` — по ним подобрать таймер; темп — 10 с между фильмами, только **один** цикл (семафор google_tv).
   Прежняя формулировка: просмотрено + есть в магазине + не куплено + не в желаемом → нажать
   «Добавить в список желаний». Владелец явно попросил эту операцию (2026-10-23); делать по каждому тайтлу,
   проверять, что добавилось. Это долгая операция — запускать отдельной фоновой сессией.
5. **Язык озвучки** (не субтитры): для купленного и желаемого записать доступные языки озвучки.
   Куплено только с английской озвучкой, а в магазине есть версия с RU или UK озвучкой → добавить эту версию
   в желаемое. Если подходящих версий несколько — выбирать RU озвучку, затем UK.
6. **Привязать к тайтлам**: `python -X utf8 -m films link stores`. Купленное заводится тайтлом за любые годы (вторая
   основа БД). Названия чистятся от изданий/«(2019)»/«DCU:», «RU (EN)» делится; ремейки различаются по длительности
   (`duration` ±4 мин, ближайшая); Google Play берёт IMDb id у своей покупки YouTube (`youtube_library_vid`).
   Не сопоставилось — найти вручную, сверить в TMDB название+год+длительность, записать в `raw.imdb_ids` с
   `imdb_source = "manual <дата> (…checked)"` и перезапустить. В отчёте — что осталось несопоставленным.
7. Записать `checked_at`, пересобрать таблицу (`rebuild-sheet`), отчитаться: сколько куплено, в желаемом,
   добавлено, со скидкой (список со скидками отдельно), отсутствует в магазине.

Ничего не покупать. Покупка — только по отдельной явной просьбе владельца с подтверждением суммы.

## Цикл «Хочу посмотреть» Google TV — как запускать (2026-10-24)

Вкладка google.com → загрузить `films/browser/gtv_watchlist_guard.js` **как есть** (хук сверяет текст) → `films/browser/gtv_loop.js`
→ `__gtvLoop(items)` один раз (список сохраняется в localStorage `gtvItems`; после перезапуска вкладки — `__gtvLoop()`
без аргументов, уже обработанное пропускается). Таймеры страницы — через Worker: Chrome душит таймеры фоновой вкладки до
одного пробуждения в минуту (фильм шёл ≈ 3 мин, с Worker ≈ 17 с). Второй цикл не стартует (heartbeat `gtvBeat`). Проверка каждые
10 минут (cron + хук `gtv-tick.sh`): нет ответа / heartbeat > 3 мин → закрыть вкладку и перезапустить. Отчёт по каждому
фильму: коды `id:A/U/I/N/E` из вкладки (страница google.com не достучится до локального приёмника) →
`data/cache/stores/gtv_codes.txt` → `python -X utf8 -m films.gtv_report` (+ загрузка в store_items).

**Хвост «нет карточки» (R147, 2026-10-24).** Предохранитель сравнивает названия по словам — у карточки Google может быть
другое написание («Район № 9», «Битлджус 2», англ. название аниме). Порядок: проба «Начало» 2010 (нет карточки → блок
Google, не обходить) → перечитать карточки только чтением (iframe поиска «<название> <год> фильм», `data-attrid="title"` /
`"subtitle"`, пауза 3 с, без слов кнопки списка — хук `gtv-guard.sh`) → совпало после нормализации (№, пробелы, знаки) и год ±1 —
`__gtvGuard.add({id, names: [orig, ru, название карточки], year})` → иначе спросить владельца **по одному фильму на вариант**
с «N/M» (скил owner-survey) → подтверждённые тем же `add`. Проверять самому, что карточка — тот же фильм: «Покемон 14:
Виктини и Белый герой» ≠ наш «Чёрный герой», «Дэдпул 2» ≠ «Жил-был Дэдпул». Карточка без года — предохранитель не
подтвердит, в отчёт. Причины по каждому — `data/cache/stores/gtv_tail_cards.json` → `films.gtv_report`.
