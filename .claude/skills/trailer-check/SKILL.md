# Проверка языка трейлера

Название ролика ничего не доказывает: «Русский трейлер» часто — оригинал с русскими субтитрами. Трейлер в
таблице должен быть **с русской речью**. Порядок проверки (от дешёвого к дорогому, указание владельца 2026-10-23):

1. **Страница ролика** — язык звуковой дорожки / автоматических субтитров YouTube (`audio_lang`). Русский → подтверждено.
2. **Субтитры** — ручная русская дорожка субтитров при неизвестной речи = подсказка «оригинал с субтитрами» (не решение).
3. **Звук** — скачать аудио (yt-dlp, ~1–3 МБ), перевести ffmpeg в 16 кГц, распознать речь локальной моделью
   faster-whisper (`small`, CPU) по участкам с речью; русский при вероятности ≥ 0.7 и кириллице в расшифровке →
   подтверждено. **Файл сразу удаляется**, папка `data/cache/trailer_audio/` чистится в конце прогона.
   Метаданные YouTube «не русский» тоже перепроверяются звуком — они ошибаются (был «Хороший партнёр»: asr `en`,
   а речь русская 97%).
3б. **YouTube требует вход** («Please sign in», возрастное ограничение) — страницу ролика читать в Chrome владельца
   (он залогинен; разрешение владельца 2026-10-23): одна вкладка youtube.com, одним `javascript_exec` пачкой
   `fetch('/watch?v=ID')` по всем таким роликам → `ytInitialPlayerResponse`: `captions…captionTracks` (`kind: asr` =
   язык речи) и `streamingData.adaptiveFormats[].audioTrack` (исходная дорожка, `isAutoDubbed`). Вердикт дописать в
   `audio_checks.jsonl` с `method: "chrome:…"`, вкладку закрыть. Куки браузера в yt-dlp не передавать.
4. Не русская речь → **альтернативы**: остальные кандидаты того же тайтла из поиска + запрос «… трейлер дубляж»;
   первый подтверждённый по звуку заменяет ссылку. Нет — ссылка убирается (только найденные нами,
   `trailer_ru_source = 'youtube_search'`; TMDB-ссылки не трогаем), вывод остаётся в журнале.

## Если русского нет — трейлер всё равно должен быть (владелец, 2026-10-23)
Порядок: русская озвучка (TMDB/YouTube) → украинская (YouTube/TMDB) → оригинал (TMDB, потом поиск YouTube) →
оригинал с русскими субтитрами → любой трейлер этого тайтла в лучшем качестве (4K/HD в названии).
`python -X utf8 -m films.sources.trailer_lang fallbacks` (из найденного) и `originals` (поиск YouTube) →
`titles.trailer_alt_*`; в таблице ссылка «Трейлер (укр / ориг. / рус. суб. / другой)».

## Команды
```
python -X utf8 -m films.sources.trailer_lang check --unconfirmed --dry-run   # сначала всегда пробно
python -X utf8 -m films.sources.trailer_lang check --unconfirmed             # применить
python -X utf8 -m films.sources.trailer_lang check --ids 12,34               # конкретные тайтлы
python -X utf8 -m films.sources.trailer_lang video <youtube_id>              # один ролик, вердикт
```
Вердикты кэшируются в `data/cache/youtube/audio_checks.jsonl` (повторный прогон берёт их оттуда; ошибки скачивания
не кэшируются). Долгий прогон — фоном + сторож агентов (CLAUDE.md).

## Отчёт владельцу
Сколько подтверждено (и каким способом), сколько заменено (было → стало), сколько убрано, сколько осталось
«неизвестно» (мало речи / не скачалось) — эти списком. Записать итог в PLAN.md.

Зависимости: `yt-dlp`, `faster-whisper` (requirements.txt), системный `ffmpeg`. Модель Whisper скачивается один раз
в кэш HuggingFace. CUDA не нужна (на GPU без CUDA 12 runtime падает — поэтому CPU).
