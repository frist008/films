# Проверка языка трейлера

Название ролика ничего не доказывает: «Русский трейлер» часто — оригинал с русскими субтитрами. Трейлер в
таблице должен быть **с русской речью**. Порядок проверки (от дешёвого к дорогому, указание владельца 2026-10-23):

1. **Страница ролика** — язык звуковой дорожки / автоматических субтитров YouTube (`audio_lang`). Русский → подтверждено.
2. **Субтитры** — ручная русская дорожка субтитров при неизвестной речи = подсказка «оригинал с субтитрами» (не решение).
3. **Звук** — скачать аудио (yt-dlp, ~1–3 МБ), перевести ffmpeg в 16 кГц, распознать речь локальной моделью
   faster-whisper (`small`, CPU) по участкам с речью; русский при вероятности ≥ 0.7 и кириллице в расшифровке →
   подтверждено. **Файл сразу удаляется**, папка `data/cache/trailer_audio/` чистится в конце прогона.
   Метаданные YouTube «не русский» тоже перепроверяются звуком — они ошибаются (был «Хороший партнёр»: asr `en`,
   а речь русская 97%).
3а. **Звук без VAD** (если шаг 3 сказал «неизвестно»; agent_trailers3, 2026-10-25 — так решились почти все «спорные»).
   Под музыкой трейлера VAD (Silero) выкидывает всю речь: `speech_seconds 0`, «en 0.368» = данных нет. Тогда
   `speech_language_v2` в `films/sources/trailer_lang.py`:
   - аудио режется на окна по 30 с (от 0 с, потом от 15 с), каждое распознаётся с автоопределением языка; хвост < 10 с
     не берётся (на тишине Whisper сочиняет фразы);
   - считаются только уверенные окна: вероятность ≥ 0.7 и ≥ 2 настоящих слов. **Не речь** (`speech_words`, `is_filler`):
     звуковые пометки Whisper («НАПРЯЖЕННАЯ МУЗЫКА», «[MUSIC]», слова КАПСОМ), повторяющийся припев («Superman!» ×11 = одно
     слово), известные выдумки Whisper на музыке («Субтитры сделал…», «Продолжение следует…», «Спасибо за просмотр»);
   - **русский** (`window_verdict`): ≥ 3 русских слов кириллицей без украинских букв и минимум вдвое больше слов, чем у
     уверенно распознанных других языков (русская фраза «Скоро в кино» под английским диалогом — не русский трейлер);
     другой язык — ≥ 5 слов и вдвое больше;
   - не решилось → **островки речи** по 8 с (`island_verdict`): язык каждого куска; уверенно русский кусок
     распознаётся по-русски и засчитывается только с настоящими словами (короткие реплики под музыкой, «Супермен»).
   Вердикт в `audio_checks.jsonl` с `method: "speech_v2 …"`, прежний ответ — в поле `v1`; закэшированный старый «неизвестно»
   перепроверяется этим шагом один раз сам (`trailer_lang check`). Скачивание звука идёт через общий темп YouTube
   (`films.locks.pace('youtube_http')`), 429 / проверка на бота → остановка сразу.
   Тесты правил текста: `python -X utf8 -m unittest tests.test_trailer_lang`.
3б. **YouTube требует вход** («Please sign in», возрастное ограничение) — страницу ролика читать в Chrome владельца
   (он залогинен; разрешение владельца 2026-10-23): одна вкладка youtube.com, одним `javascript_exec` пачкой
   `fetch('/watch?v=ID')` по всем таким роликам → `ytInitialPlayerResponse`: `captions…captionTracks` (`kind: asr` =
   язык речи) и `streamingData.adaptiveFormats[].audioTrack` (исходная дорожка, `isAutoDubbed`). Вердикт дописать в
   `audio_checks.jsonl` с `method: "chrome:…"`, вкладку закрыть. Куки браузера в yt-dlp не передавать.
4. Не русская речь **или речь так и не определилась** → **альтернативы**: остальные кандидаты того же тайтла из поиска +
   запросы «… трейлер дубляж» по русскому и оригинальному/латинскому названию; первый подтверждённый по звуку заменяет
   ссылку. Кандидат отбрасывается, если ролик не играет, длиннее 5 мин или **загружен раньше чем за 400 дней до выхода
   тайтла** (`uploaded_too_early`: старый ролик с тем же русским названием — другой фильм или канал нарезок; так отсеялись
   «Синяя коробка» 2024 для фильма 2026, «Исчезнувший» = My Son 2021 для Kill Me Now 2022). Совпадение названия — не
   доказательство: «Мамин диван» для «Эллен», «Друзья и соседи» для «Соседей», «Первый мститель» для «Капитана Америки»
   1990 — чужие фильмы (флаги поиска `name_extended` / `partial_name` / `many_other_words` = не этот фильм).
   Нет альтернативы: не русская речь → ссылка убирается из русских, а сам ролик становится запасным трейлером
   (`trailer_alt_kind` = `uk` / `ru_sub` при ручных русских субтитрах / `original`), если запасного не было или он хуже;
   «неизвестно» → ссылка остаётся с `trailer_ru_check = 'unknown'`, вопрос владельцу (формат owner-survey, по одному
   тайтлу, ссылка гиперссылкой перед вопросом: `data/cache/survey_queue/trailers_left.json`).

## Как показывать владельцу нерешённый трейлер (владелец, 2026-10-25)
Владелец: «где написано, сколько времени идут другие и какой там язык? Я вижу один. Как мне выбрать?» и «если время
одинаковое или почти одинаковое с разных каналов — это одно и то же, мне нужны реально разные длительности и их язык».
- Искать широко: русское, оригинальное, латинское, украинское названия × «трейлер», «тизер», «трейлер 2», «дублированный
  трейлер», «trailer», «teaser». Игровые трейлеры, прохождения, обзоры, реакции, клипы, фанатские монтажи («fan»,
  «re-cut», «modern trailer», «… trailer style», анимированные пересказы, Roblox/GTA/Minecraft), трейлеры серий и
  сериалов с тем же словом в названии («ЧУЖАК … ПУТЬ СИНОБИ», «For Honor — Синоби») — выбросить. Латинское название
  без русского / оригинального засчитывается только с годом (±1), именем актёра/режиссёра или если в нём 3+ слова
  («Hidden Blade» — это и Assassin's Creed, и японский фильм 2004).
- **Ролики с длительностью ±3 с — одна версия** (одна нарезка, перезалитая разными каналами). От версии — одна лучшая
  загрузка (официальный / подтверждённый канал, 4K/HD, больше просмотров); если среди загрузок есть «рус./дубляж» —
  проверить и её: версия русская, если русская хоть одна загрузка.
- По каждой версии: **длительность, язык по проверке звука** (русский / английский / китайский / … / «речь не распознана
  (под музыкой)» — уверенной речи не найдено: только музыка или речь, которую распознавание не отделило от музыки, —
  не писать «речи нет», если не проверено ушами), **короткая цитата** услышанного, ссылка, пометка «сейчас стоит».
- Вопрос — один фильм; варианты — версии «45 с — русский», «2 мин 10 с — английский» (до 3, русские и стоящая сейчас
  первыми) + «Ни один»; полный список версий гиперссылками (`links_markdown`) — сообщением перед вопросом.
  Готовые вопросы — `data/cache/survey_queue/trailers_left.json`.
- **Команда:** `python -X utf8 -m films.sources.trailer_lang cuts <id> [<id> …]` — поиск, фильтры (`cut_title_ok`),
  группы ±3 с (`group_cuts`), лучшая загрузка (`best_upload_key`), проверка звука, вопросы (`cuts_question`);
  данные по версиям — `data/cache/trailer_cuts.json`, вопросы — `trailers_left.json` (перезаписывается переданными
  тайтлами, нумерация «N/M ·» заново); `--no-questions` — только данные. **Просмотренное пропускается** (владелец,
  2026-10-25: «Не нужны трейлеры для фильмов, которые я видел»; `youtube.NOT_WATCHED`), как и в `check --unconfirmed`.
  Тесты: `python -X utf8 -m unittest tests.test_trailer_lang`.

## Значения `titles.trailer_ru_check`
`audio_track` / `asr` (метаданные YouTube), `speech` (распознавание звука, v1 или v2) — подтверждено;
`teaser_only` — русская речь подтверждена, но ролик короче 1:30, а более длинного русского нет (ставят поисковые прогоны;
плейлисты такой тизер принимают); `no_speech` — у фильма нет диалогов (TMDB язык речи «xx», напр. «Поток» / Flow) и в
трейлере речи нет: ссылка остаётся без вопроса владельцу; `unknown` — речь не определилась, ждёт владельца;
`neural` / `other` — не русский трейлер; `owner` — владелец послушал версии и выбрал русскую (`trailer_ru_source = 'owner'`),
не перепроверять; `owner_none` — владелец сказал, что русской нет (выбранная им версия — в `trailer_alt_url`), поиск
русского трейлера этот тайтл больше не берёт. `check --unconfirmed` берёт всё, кроме `audio_track` / `asr` / `speech` /
`teaser_only` / `no_speech` / `owner`. Просмотренные тайтлы трейлеры не ищут и не перепроверяют (владелец, 2026-10-25).

## Deno для yt-dlp (JS-проверки YouTube)
Без JavaScript-движка yt-dlp для части роликов пишет «This video is not available» (YouTube требует решить JS-проверку),
и звук таких роликов не проверить. **Deno установлен 2026-10-25** по ответу владельца «Да, поставить Deno»; решатель
проверок — пакет `yt-dlp-ejs` (ставится вместе с `yt-dlp[default]`, с GitHub ничего не скачивается —
`--remote-components` не включаем). Код запускает yt-dlp с `js_runtimes = {"deno": {}}` (`trailer_lang._download_audio`).
- Новая машина: `winget install DenoLand.Deno` и `pip install -U "yt-dlp[default]"` (то же — в docs/google-setup.md,
  «Новая машина»).
- Проверка: `python -m yt_dlp --js-runtimes deno --simulate 92cxXDyL_fU` — должен показать ролик (81 с, «Кунг-Фу Панда:
  Загадки свитка»), а не «This video is not available».

## Если русского нет — трейлер всё равно должен быть (владелец, 2026-10-23)
Порядок: русская озвучка (TMDB/YouTube) → украинская (YouTube/TMDB) → оригинал (TMDB, потом поиск YouTube) →
оригинал с русскими субтитрами → любой трейлер этого тайтла в лучшем качестве (4K/HD в названии).
`python -X utf8 -m films.sources.trailer_lang fallbacks` (из найденного) и `originals` (поиск YouTube) →
`titles.trailer_alt_*`; в таблице ссылка «Трейлер (укр / ориг. / рус. суб. / другой)».

## Команды
```
python -X utf8 -m films.sources.trailer_lang check --unconfirmed --dry-run   # сначала всегда пробно
python -X utf8 -m films.sources.trailer_lang check --unconfirmed             # применить
python -X utf8 -m films.sources.trailer_lang check --ids 12,34               # конкретные тайтлы
python -X utf8 -m films.sources.trailer_lang video <youtube_id>              # один ролик, вердикт
python -X utf8 -m films.sources.trailer_lang cuts 2827 6870                  # разные версии трейлера → вопросы владельцу
```
Вердикты кэшируются в `data/cache/youtube/audio_checks.jsonl` (повторный прогон берёт их оттуда; ошибки скачивания
не кэшируются). Долгий прогон — фоном + сторож агентов (CLAUDE.md).

## Отчёт владельцу
Сколько подтверждено (и каким способом), сколько заменено (было → стало), сколько убрано, сколько осталось
«неизвестно» (мало речи / не скачалось) — эти списком. Записать итог в PLAN.md.

Зависимости: `yt-dlp`, `faster-whisper` (requirements.txt), системный `ffmpeg`. Модель Whisper скачивается один раз
в кэш HuggingFace. CUDA не нужна (на GPU без CUDA 12 runtime падает — поэтому CPU).

## Трейлеры сезонов (V4, 2026-10-29)
Сезон ≥ 2 несёт только свой трейлер: в названии ролика (настоящем, со страницы просмотра YouTube) назван этот сезон, или без номера — выложен в окне этого сезона (после премьеры прошлого + 30 дней, до премьеры + 60 / следующей − 91, не раньше 400 дней до премьеры). Общий трейлер всего сериала (выложен после всех сезонов, «32 Seasons», «все сезоны») — у всех сезонов (владелец: «Оставить у всех сезонов»). Номер, которого нет в TMDB («Futurama Season 14» при 11 сезонах TMDB), — другая нумерация канала, оставить. Удалённые ролики снимать. Проверка: `python -X utf8 -m films.season_trailers check` (сухо) → `--apply`; потом `trailer_lang.fill_fallbacks(only_missing=True)` и `search_originals`, пока сухая проверка не даст 0 неверных.
