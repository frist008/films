# Изменения

## 1.0.0 — 2026-10-25

Первая полная версия: база ведётся постоянно, её может подхватить любой аккаунт Claude (CLAUDE.md, скилы
`.claude/skills/*`, раздел PLAN.md «При следующем обновлении базы»).

- **Раздачи.** rutor за 2024+ по категориям 1/4/7; франшизы и вселенные владельца — за все годы (в т. ч. 43 франшизы по его
  играм); всё, что владелец «встретил» (очередь qBittorrent, скачанное в Plex/Jellyfin/на дисках, его списки), — за любые годы
  (`films.encountered`); раздача из адреса в его торрент-файле; модуль rutracker — сбор одним JS-вызовом в Chrome.
- **Сопоставление.** IMDb со страницы раздачи (id эпизода не принимается), разбор однофамильцев, запасной поиск TMDB
  (оригинальное / латинское / русское название — отдельными запросами), «3D», сборники только при диапазоне лет.
- **Метаданные и рейтинги.** TMDB; IMDb из датасетов для всех связанных тайтлов любых лет; Rotten Tomatoes;
  тех. характеристики IMDb; вердикт апскейла (IMDb DI + blu-ray.com).
- **Качество.** Озвучка важнее качества; DV, пересобранный из HDR10/HDR10+; DV5 без HDR10 — исключается («Dolby Vision TV»
  у ремукса — не профиль 5); озвучка-приоритет для отдельных сериалов (`[voice_preference]`).
- **Медиасерверы.** Plex, Jellyfin, диски, qBittorrent — скачанное и просмотренное; распознавание файлов по nfo, путям,
  именам и дискам; сверка торрента с раздачей по размеру.
- **Таблица.** Листы: Главная, Сериалы, Мультфильмы, Мультсериалы, Аниме, Обновить качество, Просмотренные, Купить,
  Плейлисты, Нет на трекерах, Баллы, Все; сортировка баллами за признаки (веса согласуются при следующем обновлении).
- **Плейлисты трейлеров** (Дима, Яна, «Костя Хочет», «Вероятно», «Возможно»), русские трейлеры с проверкой речи.
- **Google TV.** Список «Хочу посмотреть» — только через предохранитель; отчёт по каждому фильму.
- **Обновление.** `films update --start/--finish`: события и отчёт об изменениях.
- **Безопасность.** Предохранители Plex и Google TV, хуки правил владельца, проверка приватности перед пушем, аудит
  понятности вопросов.
