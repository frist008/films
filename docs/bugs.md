# Журнал багов: каждый баг — со стражем в коде

Владелец, 2026-10-25: «Баги настолько часто, что исправлять надо кардинально». Правило: баг, который заметил владелец,
**не считается исправленным, пока его повтор не ловит код** — хук (`.claude/hooks/*`), тест (`tests/*`) или проверка
в модуле. Правило в памяти/скиле без кода — не страж. Порядок:

1. Сообщение владельца о баге → строка здесь (дата, его слова, причина, страж) **в том же ходе**, что и исправление.
2. Страж сначала проверяется на повторе (pipe-тест хука, падающий без исправления тест), потом коммит.
3. Stop-хук `plan_guard.py` проверяет, что у каждой строки есть страж и его файлы существуют.
