# Франшизы: состав вселенных (R34)

Реализация от 2026-10-23. Модуль: `films/franchise.py`, тесты: `tests/test_franchise.py`.
Результат: таблица `franchise_members` (миграция 7) + подробности по каждой франшизе в
`data/cache/franchise/resolved/<key>.json` (сиды, страницы, вики, доказательства, нерешённое, исключённое, ошибки).

## Определение (владелец, 2026-10-23)

Франшиза — **вся вселенная**: номерные фильмы, спин-оффы, приквелы, перезапуски и ремейки той же IP, сериалы по
фильмам и фильмы по сериалам, анимационные фильмы и сериалы, спецвыпуски. Не только коллекция TMDB и не по
совпадению названия. Примеры владельца: Джон Уик ⇒ «Балерина» и «Континенталь»; «Каратель — это Marvel» ⇒ зонтик
Marvel = MCU + Люди Икс Fox + Человек-паук/Веном Sony + Каратель, Блэйд, Призрачный гонщик, Сорвиголова,
Фантастическая четвёрка, сериалы Netflix/Disney+; DC так же (вкл. Константина, Хранителей, анимацию DC);
League of Legends ⇒ «Аркейн» и другие экранизации Рунтерры; Хэллоуин — вкл. фильмы Роба Зомби; Мортал Комбат —
игровые фильмы и анимация MK Legends; Планета обезьян — `from_year = 2011` (только перезапуск).

## Команды

```bash
python -X utf8 -m films.franchise resolve                       # все франшизы из config/franchises.toml
python -X utf8 -m films.franchise resolve --only tmdb_404609,dc  # выборочно
python -X utf8 -m films.franchise resolve --refresh             # перезапросить всё (кэш игнорируется один раз)
python -X utf8 -m films.franchise report [--review] [--source-diff]
python -X utf8 -m films.franchise show tmdb_404609 [--evidence] [--confidence review]
python -X utf8 -m unittest tests.test_franchise
```

`--workers N` — сколько франшиз параллельно (по умолчанию 2; лимиты на хост общие для всех потоков).
`--sources tmdb,wikidata,wikipedia,fandom` — отладка: только часть источников.

## Источники и как они используются

| Источник (метка в `sources`) | Что берём |
|---|---|
| `tmdb_collection` | части коллекций TMDB из `franchises.toml` (`films.sources.tmdb`, кэш `tmdb_raw`) → IMDb id. Это и «якоря» для Wikidata |
| `wikidata` | SPARQL `query.wikidata.org`. Якоря (части коллекций, по P345/P4947) → их P8345 «медиафраншиза», P179 «часть серии», P1434 «место действия — вымышленная вселенная», P361 «часть» = **сиды**; от сида на 1–2 уровня вверх (серия фильмов → франшиза). Затем вниз: всё, что ссылается на сид/подсерию через P8345 / P179 / P1434 / P1080 / P361 или указано в P527 «состоит из», с обходом подфраншиз и серий фильмов. **Слабые** связи: «основано на» (P144) члене франшизы, соседи P155/P156, производные P4969. Для зонтиков (marvel, dc): производство (P272) Marvel Studios / Marvel Television / … / DC Entertainment / DC Studios; основано на персонаже или работе вселенной (Marvel Universe / DC Universe) или издателя; персонажи (P674) из вселенной — слабая связь |
| `wikipedia:en`, `wikipedia:ru`, `wikipedia:uk` | статьи сидов (только разделы о фильмах/сериалах, и в них только строки-списки: заголовки, таблицы, пункты, `{{Main}}` — не проза), навигационный шаблон сида (P1424, без групп «игры/комиксы/книги/люди»), дерево категории сида (P910, 2 уровня, только подкатегории о фильмах/сериалах). Для зонтиков — кураторские списки (`List of films based on Marvel Comics publications` и т.п.; ru/uk-версии — через sitelinks того же элемента Wikidata). Ссылки → элемент Wikidata через sitelinks (SPARQL), остаток — через `pageprops` с редиректами. Непереведённые ссылки ru/uk (`{{Нп3|…|en|English title}}`) разрешаются через английскую статью |
| `fandom:<вики>` | **только кураторский список** вики в `EXTRA` (проверены: существуют и посвящены именно этой франшизе). Wikidata P6262 сидов/якорей указывает и на общие вики (зеркала TV Tropes, базы дубляжа, Memory Alpha, «to-hollywood-and-beyond» — тысячи чужих фильмов), поэтому такие вики только показываются в отчёте как `fandom_suggested`. Категории фильмов/сериалов ищутся поиском по пространству «Категория» и фильтруются по названию (`fandom_category_ok`; «(real-world)» — внешний мир, допустимо), с подкатегориями на 2 уровня. Страница → IMDb: ссылка imdb.com/title на странице или поле/шаблон IMDb в вики-тексте; иначе — точное совпадение названия (+год из названия/инфобокса, тип) с работой, которую **другой источник уже твёрдо отнёс** к франшизе (сильная связь Wikidata, коллекция TMDB или Википедия на ≥ 2 языках) — так fandom только подтверждает, но не добавляет; иначе — в «нерешённые». **Совпадение только по названию (поиск TMDB) новую работу не создаёт** (2026-10-23: вики halloween.fandom.com оказалась вики праздника, поиск по названию дал 340 чужих фильмов — «Пила», «Чужой», «Носферату»…). Защита: если у вики ≥ 10 работ и < 25 % из них знает другой источник — вики считается «не той», её собственные работы не сохраняются (в `excluded`) |
| `curated` | работы-«якоря», выбранные вручную по заметке владельца в `franchises.toml` для франшиз без коллекции TMDB (`anchors_imdb` / `anchors_qids` в `EXTRA`: «Джентльмены» 2019 + сериал 2024, «Южный парк», «Тетрадь смерти», «Русалочка», «101 далматинец»…). Считаются отдельным семейством источников |


Тип работы проверяется по классам Wikidata (P31 → P279*): фильм / проект фильма / телефильм, сериал / веб-сериал /
мини-сериал, телепрограмма, спецвыпуск, пилот, короткометражка, документальный, анимация/аниме. **Исключаются**:
эпизоды, сезоны, видеоигры, «вымышленные фильмы» (фильм внутри сюжета), реклама, клипы, трейлеры, брошенные проекты,
фанфильмы; не-экранные элементы (персонажи, книги, комиксы, игры, люди) — молча (это шум ссылок).
Вид (`kind`): film / animated film / series / animated series / special / short / documentary — по Wikidata
(классы и жанр P136) и TMDB (тип movie/tv, жанры 16 «анимация», 99 «документальный», хронометраж < 40 мин = short).

## Уверенность (`confidence`)

- `confirmed` — работу назвали **≥ 2 семейства** источников: wikidata / wikipedia / fandom / tmdb_collection / curated.
  Три языка Википедии — одно семейство (ru и uk часто переведены с en), несколько fandom-вики — тоже одно.
- `single_source` — одно семейство.
- `review` — сомнительно при любом числе источников (флаг в `note`):
  - `weak_link_only` — только слабая связь Wikidata (основано на / сосед / персонаж / производная);
  - `imprint` — по комиксу импринта (Vertigo, WildStorm, Paradox, Black Label, ABC, Icon, Malibu, Epic, Star Comics),
    без связи с общей вселенной;
  - `documentary_unofficial` — документальный без структурной связи (не из коллекции TMDB, нет сильной связи Wikidata);
  - `pilot` — телепилот; `parody` — жанр Wikidata «пародия» / «порнопародия» / «порнофильм»;
  - `fandom_only` — знает только fandom (категории фильмов на fandom включают и фильмы с камео/отсылками);
  - `one_wikipedia_only` — знает только Википедия на одном языке (кроме кураторских списков);
  - `unverified` — IMDb id неизвестен ни Wikidata, ни TMDB (тип не проверить);
  - `stale: …` — строку прошлого прогона новый прогон не нашёл.

Таблицу ранжирования (`films/rank.py`) строки `review` не поднимают — их решает владелец.

`sources` — JSON-список меток; `note` — QID Wikidata и флаги. Полные доказательства (какая страница/раздел/
свойство) — в `resolved/<key>.json`, команда `show --evidence`.

## Решения

- **Без элемента франшизы в Wikidata** (у частей коллекции нет P8345/P179 — так у ~70 франшиз, в основном
  2020-х): Википедия читается по статьям самих якорей (только разделы «Продолжение / Сиквел / Франшиза / Сериал…») и
  по их навбоксу франшизы — шаблону, стоящему отдельной строкой в статьях якорей и ссылающемуся на ≥ 2 якоря;
  навбоксы людей и компаний (тема P1423 или одноимённая статья — человек / компания: «Sam Raimi», «Takashi
  Shimizu») отбрасываются, остальные принимаются, если тема — произведение/франшиза, имя совпадает с коллекцией или
  якоря составляют ≥ 25 % ссылок. Так «Проклятие» (The Grudge) получает всю японскую «Ju-on».
- **Каталоги студий не обходятся**: серии вида «Walt Disney Animation Studios feature film», «Studio Ghibli Feature
  Films», «Pixar universe», «DreamWorks universe», «Warner Bros. universe» (регэксп `STUDIO_CATALOGUE` +
  `GLOBAL_SEEDS_EXCLUDE`); вверх от якорей — только по P8345/P179 (через P361/P1434 цепочка уходила в «вселенную
  Pixar» и давала все мультфильмы студии).
- **Персонаж как франшиза** (Шерлок Холмс, «все экранизации»): все работы с персонажем (P674) или по произведению с
  ним (P144 → P674) — сильная связь, + статья «Adaptations of Sherlock Holmes».
- **Экранизации игр** (`source = "games"`): строки таблицы `game_adaptations` (без `stale`) нужной серии игр
  (`game_groups` в `EXTRA`) — источник `game_adaptations`; он собран из тех же Wikidata/Википедии, поэтому
  **не считается независимым** семейством при подсчёте `confirmed`. Серии игр — дополнительные сиды.
- **Пародии**: флаг `parody` не ставится во франшизах, которые сами пародийные (половина якорей — жанр «пародия»:
  «Очень страшное кино», «Голый пистолет»).
- **scope = "none"** — не собираются (владелец: без приоритета), `--all-scopes` включает.
- «Космический джем»: вселенные Looney Tunes / Bugs Bunny (все короткометражки с 1930-х) не обходятся — решение
  за владельцем.

- **Документальные**: хранятся с `kind = 'documentary'` (их легко исключить в ранжировании). Официальными
  считаются те, что связаны с франшизой структурно (коллекция TMDB или сильная связь Wikidata); остальные (найдены
  только в статьях/навбоксах/fandom, напр. «Wick Is Pain») — `review` с флагом `documentary_unofficial`.
  Ретроспективы и making-of, которые не являются элементами Wikidata с IMDb id, в базу не попадают.
- **Анонсированные** работы — только с IMDb id (PK таблицы); без IMDb — в «нерешённые» отчёта.
- **from_year** (Планета обезьян, 2011): работы с известным годом раньше границы не пишутся (видны в
  `dropped_years`); работы без года (анонсы) остаются.
- **Ничего не удаляется**: повторный `resolve` обновляет строки; не найденные теперь — `review` + `stale: …`.
- Версии (режиссёрская/театральная) с собственным IMDb id остаются (флаг `version`).

## Вежливость и кэш

- Только HTTP (`requests`), без браузера. User-Agent `films-db/1.0 (…; personal, non-commercial film catalogue)`.
- Wikimedia (все `*.wikipedia.org` + action API `www.wikidata.org`) с 2026 года ограничивает клиентов **на всех
  сайтах сразу**: User-Agent без контакта = «неопознанный» клиент = **10 запросов/мин**; с контактом (e-mail или
  URL) — 200/мин ([политика](https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits)). Поэтому:
  - всё, что можно, берётся через SPARQL (`query.wikidata.org` под этот лимит не попадает; пауза 1 с);
  - запросы к Википедии идут не чаще 1 раза в 6,5 с (общая очередь для всех языков и потоков); статьи и
    навбоксы — пачками по 50 страниц в одном запросе;
  - контакт можно задать в `FILMS_CONTACT` (переменная окружения или строка в `.env`, который не попадает в git) —
    тогда пауза 0,55 с. Значение нигде не печатается и не сохраняется. Без него полный прогон всех франшиз
    занимает несколько часов (почти всё время — Википедия).
- Остальные хосты (fandom, TMDB): ≤ 2 запроса/с на хост; 429/5xx/сетевые ошибки — повтор с экспоненциальной паузой,
  `Retry-After` учитывается (и задерживает всю очередь хоста).
- Сырые ответы — `data/cache/franchise/<host>/…json.gz`, элементы Wikidata — `data/cache/franchise/entities/`,
  замыкание классов — `class_roots.json` (всё в `.gitignore` через `data/cache/`). Свежесть — 30 дней,
  `--refresh` — перезапросить.

## Кураторские дополнения (`EXTRA` в `films/franchise.py`)

Где автоматики мало, в коде есть проверенные вручную дополнения — каждое с комментарием:
- `seeds` — дополнительные элементы Wikidata (MCU, вселенная Sony, «Человек-паук в кино», Люди Икс, ФЧ,
  «Каратель в кино», Веном, сериалы Marvel/Netflix, Marvel Animated Features; DCEU, DCU, DCAU, Arrowverse,
  Tomorrowverse, DC Universe Animated Original Movies, «Бэтмен/Супермен в кино», DC Elseworlds; League of Legends —
  медиафраншиза, вселенная, серия игр, т.к. коллекций TMDB у неё нет);
- `umbrella` — вселенные, издатели, импринты и студии для Marvel и DC;
- `wikipedia` — списки (по английскому названию; ru/uk — через Wikidata);
- `fandom` — проверенные fandom-вики (существуют и посвящены франшизе); `fandom_skip` — нерелевантные
  (weapons.fandom.com — про настоящее оружие; Marvel Database — комиксы).
