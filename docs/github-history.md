# История на GitHub: один коммит

Владелец, 2026-11-14: «Надо будет после пуша сделать так чтобы в гитхабе был один пуш и история потерта, чтобы мы не
занимали там лишнее место в не актуальной структуре» (раньше — R306 / R311, 2026-11-03: «сократи все комиты в гите до одного»).

## Каждый пуш

`python -X utf8 -m films.publish -m "сообщение"` (только после ответа владельца «Да, коммитить и пушить», хук `git-permit.sh`):
всё текущее → **один коммит без родителя** → main и тег `v1.0.0` на нём (тег на старом коммите держал бы историю живой) →
пуш с перезаписью (`+main`, `+v1.0.0`; pre-push — `films privacy-check`) → старые коммиты удаляются и локально (reflog, `gc
--prune=now`). Тест — `tests/test_publish.py`.

## Что остаётся на GitHub после перезаписи

Ветка и тег сразу показывают один коммит, но GitHub **не удаляет заменённые коммиты сразу**: они недоступны из веток, но
открываются по хешу (`/commit/<sha>`), пока GitHub сам не соберёт мусор — когда, он не обещает. Проверено 2026-11-14 после
пуша 80bda8a: в main один коммит, а 3835e39, b74a70b, 19ddefe, fffffdd по-прежнему отдаются (HTTP 200); размер
репозитория по API — 55,8 МБ при 47,3 МБ на один коммит.

Проверка (открытый API, без входа):

```bash
curl -s https://api.github.com/repos/<логин GitHub>/films | python -c "import json,sys; print(json.load(sys.stdin)['size'], 'KB')"
curl -s -o /dev/null -w "%{http_code}\n" https://api.github.com/repos/<логин GitHub>/films/commits/<старый sha>
```

**Решение владельца (2026-11-14): ничего не делать и не проверять** — «не надо ничего проверять, сам гитхаб когда-то
уберёт и всё, главное что у нас один комит и мы молодцы». Пути ниже — только если он сам попросит.

Убрать старое сразу можно только двумя путями:
1. **Пересоздать репозиторий** — владелец удаляет его (Settings → Danger Zone → Delete, подтверждение паролем — только он),
   создаётся пустой с тем же именем, `films.publish` пушит один коммит; заново включить GitHub Pages из `docs/` (страница
   privacy policy OAuth-приложения, адрес тот же).
2. **Попросить поддержку GitHub** собрать мусор / убрать закэшированные коммиты (форма поддержки, от владельца).
