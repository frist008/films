# films

A personal, non-commercial database of films, series and animation (2024 and later): releases from torrent trackers,
metadata and ratings from TMDB, IMDb and Rotten Tomatoes, a check against the owner's media servers and stores, and a
sorted Google Sheets table with trailer playlists.

- Source code: the GitHub repository this site is published from
- [Privacy Policy](privacy.md)

*This product uses the TMDB API but is not endorsed or certified by TMDB.*
