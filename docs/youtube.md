# YouTube: русский трейлер для тайтлов без трейлера

Модуль: [films/sources/youtube.py](../films/sources/youtube.py), тесты: [tests/test_youtube.py](../tests/test_youtube.py).

TMDB даёт русский трейлер только ~24% фильмов и ~11% сезонов (docs/tmdb.md). Для остальных модуль ищет ролик
поиском YouTube и пишет его в `titles.trailer_ru_url` **только если это почти наверняка русскоязычный трейлер
именно этого тайтла** (фильма или конкретного сезона). Всё сомнительное не пишется, а складывается в файлы для
просмотра владельцем.

## Запуск

```bash
python -X utf8 -m films.sources.youtube trailers                  # все тайтлы без трейлера, не проверенные за 30 дней
python -X utf8 -m films.sources.youtube trailers --limit 50       # первые 50
python -X utf8 -m films.sources.youtube trailers --recheck-days 0 # перепроверить и недавно проверенные
python -X utf8 -m films.sources.youtube trailers --ids 12,345     # конкретные тайтлы (игнорирует --recheck-days)
python -X utf8 -m films.sources.youtube trailers --dry-run --sample 100   # прогон без записи в БД
python -X utf8 -m films.sources.youtube explain 3330               # кандидаты и баллы для одного тайтла (JSON)
python -X utf8 -m films.sources.youtube search "Нежить 2024 трейлер на русском"
python -X utf8 -m films.sources.youtube report                    # сводка по последним решениям + снимки файлов
python -X utf8 -m films.sources.youtube audit [--dry-run]         # перепроверить уже записанные youtube_search-трейлеры по текущим правилам
python -X utf8 -m unittest tests.test_youtube
```

Прочие опции `trailers`: `--no-uk` (без доп. запроса украинского трейлера), `--max-hours H` (остановиться
по времени), `--offline` (только кэш).

Прогон повторяемый: тайтл берётся, если `trailer_ru_url IS NULL` и `trailer_checked_at` пуст или старше
`--recheck-days` (по умолчанию 30). Поисковые выдачи кэшируются на 30 дней, поэтому повторный прогон с новыми
правилами почти не ходит в YouTube.

## Доступ и вежливость

- Только HTTP (`requests`), без браузера и без API-ключа: `https://www.youtube.com/results?search_query=…&hl=ru&gl=UA`,
  разбор `ytInitialData` → `videoRenderer` (id, название, канал, длительность, «N лет назад», просмотры, значки
  канала, фрагмент описания).
- Не чаще одного запроса в 1.8–2.4 с на процесс (требование ≥ 1.5 с); поиск и страницы роликов — общий лимит.
- HTTP 429 / страница `/sorry/` («unusual traffic») / страница без `ytInitialData` / 5xx → пауза 60, 180, 600 с;
  если не помогло — исключение `Blocked`, прогон **останавливается** и пишет причину в итог (`stopped`).
- Окно согласия ЕС (consent.youtube.com): заранее ставится cookie `SOCS=CAI` («отклонить всё»); если окно всё равно
  пришло — повтор с cookie, после двух неудач — остановка.
- Проверка выбранного ролика: страница `watch?v=…` (см. «Проверка на странице ролика»).

## Запросы (по порядку, до первого принятого результата)

Фильм:
1. `<название RU> <год> трейлер на русском`
2. `<название RU> трейлер русский`
3. `<оригинальное название (латиница)> <год> русский трейлер`
4. `<название RU> <год> дублированный трейлер`

Сезон N: `<RU> N сезон трейлер на русском`; для 1-го сезона ещё `<RU> <год> трейлер на русском`;
`<RU> сериал N сезон трейлер русский`; `<оригинал> N сезон русский трейлер`.

Если русский не принят и в выдаче не нашлось украинского — ещё один запрос `<название UK> [<год> | N сезон]
трейлер українською` (только находка, в БД не пишется).

Отдельный поиск по каналам студий/агрегаторов дубляжа (`/@канал/search?query=…`) не делается: канал Kinoman
и другие крупные каналы русских трейлеров и так доминируют в обычной выдаче (в кэше ~960 их роликов-трейлеров из
~3000), а проверка 2026-10-23 — 15 тайтлов «не найдено» × 4 канала (Kinoman, топКино, Mister Star, FRESH Trailers),
60 запросов — не нашла **ни одного** пропущенного трейлера (поиск по каналу работает: «Кодекс Данте» находится).

## Проверка кандидата (`evaluate`)

Жёсткие правила (нарушение → кандидат отвергнут, причина в `reject`):
- в названии ролика есть RU название тайтла (нормализация: регистр, ё→е, без пунктуации; варианты — без союза
  «и», часть до двоеточия) или оригинальное/латинское название;
- после названия не стоит номер части («Нежить 2») / «часть …», кроме «N сезон»;
- есть «трейлер/тизер» (или «trailer» вместе с «русск/RU/дубляж»);
- кириллица в названии; украинские буквы/слова → отдельная находка `uk`; «субтитры/sub» в названии или в имени
  канала → находка `subtitled`; «на английском / ENG / оригинал» → отвергнут;
- не обзор / разбор / реакция / клип / сцена / отрывок / фанатский / фан-трейлер / концепт / пародия / новости / дата выхода /
  серия / эпизод / shorts / ИИ … (слова ищутся в названии ролика **без** самого названия тайтла — иначе «Теория
  хаоса» отвергалась бы как «теория»);
- длительность 0:30–5:00;
- год в названии ролика = году тайтла ±1 (для сезона N>1 допускается более ранний год старта сериала);
- опубликован не раньше 1 января (год − 2);
- фильм: ролик не про сериал/сезон; сезон: номер сезона в названии совпадает; без номера — только 1-й сезон, и
  только если ролик опубликован заметно раньше премьеры 2-го сезона.

Баллы (`score`): RU название +40 (только часть до двоеточия +22), оригинал +15 (+30, если RU нет), «трейлер» +10 /
«тизер» +5, «дубляж» +12 / «озвучка, многоголосый…» +9 / «русский» +6 / «официальный» +3, год в названии +12 (±1:
+4), год/оригинал в описании +4, номер сезона +15, доверенный канал +10, подтверждённый канал +5, просмотры до +12
(2·log10), лишние слова −6 за слово (до −30), название «продолжается» другим словом в том же фрагменте
(«Проклятые воды» для «Проклятые») −30, нейро-озвучка −10, позиция в выдаче до −5.

Имена актёров (первые 8 в титрах) и режиссёров из `credits` в названии ролика («… (2026) Джефф Дэниелс, Джаред
Харрис») не считаются лишними словами и подтверждают тайтл (`cast_in_title`). Имена в БД латиницей, поэтому
сравнение — грубая транслитерация (`translit`: daniels → даниелс) + похожесть ≥ 0.75.

## Решение (`decide`)

`accepted` — лучший кандидат с баллом ≥ 60 и **без сомнений**; иначе `ambiguous` (в БД не пишется, кандидаты в
`ambiguous.jsonl`), `not_found` — ни один кандидат не прошёл жёсткие правила.

Сомнения: балл < 60 (для «продолжающегося» названия, подтверждённого сезоном/годом **и** оригинальным
названием/актёрами, штраф −30 не учитывается: «Джек Ричер (4 сезон)» для «Ричер» S4); язык звука неизвестен и название не говорит «русский/дубляж»; нейро-озвучка; ролик
называет год раньше года тайтла и ничто другое этого не подтверждает (так отсеялся российский фильм «Она танцует»
2024 для американского «She Dances» 2025); другие загрузки этого же тайтла помечены «субтитры», а лучший не говорит «дубляж/озвучка»
(у Netflix-тайтлов русский трейлер часто только с субтитрами); название продолжается другими словами; совпала
только часть названия без подтверждения годом/оригиналом/сезоном; совпало только украинское название; много
лишних слов; 1-й сезон без номера и без года; в БД есть другой тайтл с тем же RU названием, а у ролика нет
года/оригинала; в выдаче есть ролики с тем же названием, но другим годом, а у лучшего года нет; очень короткое
название без подтверждения.

Порядок предпочтения: если есть «субтитрованные» соседи — ролик с «дубляж/озвучка» или с подтверждённым
русским звуком; полный трейлер предпочитается
тизеру, если он не хуже на 15 баллов.

## Проверка на странице ролика (язык звука, переводы названий, доступность)

Кириллица в названии **не доказывает** русский звук — это главный найденный источник ошибок:
1. YouTube показывает для `hl=ru` **переведённые** названия роликов (переводы метаданных от автора или
   автоматические): «В поисках Эмили | Официальный трейлер» у англоязычного Moviefone, «РИЧЕР 2 сезон —
   официальный трейлер» у Prime Video, Trailer Feed… Звук английский.
2. Русскоязычные каналы выкладывают **оригинальные** трейлеры с русским названием: у Melor Film «Официальный
   трейлер» = английский звук + русские субтитры, а «Русский трейлер» = русский звук.
3. YouTube добавляет к роликам **автоматический ИИ-дубляж** на десятки языков (в т.ч. русский) — такой
   «русский» трек не считается.

Поэтому выбранный ролик (а также лучший сомнительный и лучший украинский) открывается один раз:
`https://www.youtube.com/watch?v=<id>&hl=ru&gl=UA`, из `ytInitialPlayerResponse` берутся (кэш `videos.jsonl`):
- `playabilityStatus` — ролик удалён / приватный / недоступен в Украине → отвергнут (`LOGIN_REQUIRED` =
  возрастное ограничение, ролик годится); `availableCountries` без UA → отвергнут;
- `videoDetails.title` — **собственное** название ролика: если отличается от показанного в поиске, кандидат
  пересчитывается по нему (переведённое английское название → отвергнут);
- язык звука (`audio_language`): если есть автоматические ИИ-дубляжи — язык исходной (не `isAutoDubbed`)
  аудиодорожки; иначе язык единственной автоматической (`asr`) дорожки субтитров (YouTube распознаёт речь
  на языке ролика); иначе заявленная дорожка. `ru` → подтверждено (`audio_ru`); `uk` → украинская находка;
  другой язык → отвергнут, а если есть ручные русские субтитры — находка «субтитры»; неизвестно →
  `audio_unknown` (принимается, только если название говорит «русский/дубляж/озвучка», иначе сомнение).
- Если название говорит «дубляж / дублированный / озвучка», а метаданные языка — другой (встречено: Mister Star
  «Русский дублированный трейлер» с `asr = en`), верим названию и ставим флаг `audio_conflict_<lang>`.
- оригинальное название тайтла в описании ролика → `orig_in_description` (подтверждение).

- Вердикт проверки речи модулем `films.sources.trailer_lang` (скил trailer-check: Whisper по звуку,
  `audio_checks.jsonl`) при вероятности ≥ 0.7 важнее всех метаданных: ролик, где речь оказалась не русской,
  больше не будет выбран при повторных прогонах (а `trailer_lang` удаляет такую ссылку из БД).

Не больше 4 проверок страниц на тайтл; если бюджет кончился, а лучший кандидат не проверен — `ambiguous`.

## Файлы (data/cache/youtube/)

| файл | что |
|---|---|
| `searches.jsonl` | каждая выдача поиска: запрос, время, разобранные ролики (кэш 30 дней) |
| `videos.jsonl` | сведения со страницы ролика: доступность, собственное название, канал, дата публикации, аудиодорожки, субтитры, язык звука, начало описания |
| `decisions.jsonl` | решение по каждому тайтлу в каждом прогоне: статус, выбранный ролик, кандидаты с баллами и причинами, украинские/субтитрованные находки, запросы; `dry_run: true` у пробных |
| `ambiguous.jsonl` | снимок: тайтлы со статусом ambiguous (последнее решение), лучший кандидат + сомнения + запасные |
| `uk_trailers.jsonl` | снимок: тайтлы, где найден украинский трейлер (и есть ли русский) |
| `subtitled_only.jsonl` | снимок: тайтлы без русского, но с трейлером «с русскими субтитрами» |

## Запись в БД

- принят: `trailer_ru_url = https://www.youtube.com/watch?v=<id>`, `trailer_ru_source = 'youtube_search'`,
  `trailer_checked_at = now`, `updated_at = now`;
- не принят (ambiguous / not_found): только `trailer_checked_at = now`;
- каждый UPDATE с условием `trailer_ru_url IS NULL` — трейлеры TMDB (и всё, что записано параллельно) не
  перезаписываются; короткие транзакции, `busy_timeout` из `films.db.connect()` + повтор при «database is locked».

## Результаты 2026-10-23

Прогоны: пилот 80 и проверочная выборка 121 тайтл (dry-run, подбор правил); полный прогон (первые 575 тайтлов
старыми правилами, затем перезапуск с уточнёнными правилами на оставшиеся 2931); `audit` всех записанных ссылок по
окончательным правилам (1744 проверено: 1708 оставлено, 13 заменено другим роликом, 23 снято; второй проход:
1 снят); затем повторное решение по всем тайтлам без трейлера (`--recheck-days 0`, почти всё из кэша).

Последнее решение по 4247 тайтлам: **принято 2067**, сомнительно 785 (`ambiguous.jsonl`), не найдено 1395.

| | всего | принято | сомнительно | не найдено |
|---|---|---|---|---|
| фильмы | 2432 | 1382 (57%) | 420 | 630 |
| сезоны | 1815 | 685 (38%) | 365 | 765 |
| 2026 | 584 | 319 (55%) | 74 | 191 |
| 2025 | 1134 | 537 (47%) | 209 | 388 |
| 2024 | 1320 | 649 (49%) | 231 | 440 |
| ≤ 2023 | 902 | 479 (53%) | 192 | 231 |
| без года | 307 | 83 (27%) | 79 | 145 |

Язык принятых: русский звук подтверждён метаданными страницы ролика у 1889; у 70 — только название
(«дубляж/озвучка», в т.ч. при конфликте с метаданными), у 104 — только «русский трейлер» в названии (звук не
определён), у 4 — доверенный канал. Озвучка: «дубляж» в названии 603, «озвучка/многоголосый» 183, не указано 1281
(в т.ч. любительские студии вроде «Апельсинка Дубляж»).

Находки, в БД не записанные: украинский трейлер у 435 тайтлов (у 184 есть и русский; 251 — только украинский, из них
226 подтверждены звуком или словами «український/дубльований»); трейлер только с русскими субтитрами — 293.

Проверка страницы ролика отвергла: 488 роликов с нерусским исходным звуком, 186 — с переведённым YouTube названием.

Ручная проверка (по названию/каналу/длительности/дате/описанию, без просмотра): ~190 принятых и ~150 отвергнутых;
найденные ошибки (другой фильм с тем же словом в названии, английский звук при русском названии, «Чёрный лебедь.
Тайна» для «Лебедь» из-за нечёткого совпадения имени актёра, другая часть «Код Гиас») исправлены правилами и
`audit`. На финальных правилах в проверочной выборке 57 из 57 принятых верны.

YouTube не блокировал: ~15 000 запросов (поиск + страницы роликов), 0 ответов 429, 0 страниц /sorry/, 0 окон
согласия, 0 пауз.
